Visão Geral - moodle-tiny_fontfamily
====================================

O **moodle-tiny_fontfamily** é um plugin para o editor TinyMCE do Moodle que adiciona um seletor de famílias de fontes (tipografia) à barra de ferramentas e ao menu **Format**, permitindo alterar a fonte do texto selecionado.

Recursos Principais
-------------------

- **Botão na Barra de Ferramentas**: Acesso rápido à escolha de fontes na barra do TinyMCE.
- **Entrada no Menu Format**: Opção integrada aos menus contextuais de formatação.
- **Fontes Customizáveis**: Lista de famílias tipográficas gerenciada pelo administrador.
- **Detecção Inteligente**: Se menos de duas fontes estiverem cadastradas, o seletor é ocultado automaticamente para evitar interfaces vazias.
