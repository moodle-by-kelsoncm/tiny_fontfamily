Configuração
============

Configurações do Plugin
-----------------------

Acesse: **Administração do site > Plug-ins > Editores de texto > Editor TinyMCE > Família de fontes**.

Opções Disponíveis:

- **Font families**: Lista de famílias de fontes disponíveis para os usuários (uma por linha). Exemplo::

     Arial, sans-serif
     Courier New, monospace
     Georgia, serif
     Times New Roman, serif
     Verdana, sans-serif
