Guia de Uso
===========

Aplicando Fontes no Editor
--------------------------

1. Selecione o trecho de texto desejado dentro do editor TinyMCE.
2. Clique no menu suspenso **Font Family** na barra de ferramentas ou vá em **Format > Font family**.
3. Escolha a tipografia desejada para aplicar a formatação imediatamente ao texto.
