Overview - moodle-tiny_fontfamily
===================================

**moodle-tiny_fontfamily** is a plugin for Moodle's TinyMCE editor that adds a font family selector to the toolbar and the **Format** menu, allowing users to customize typography for selected text.

Key Features
------------

- **Toolbar Button**: Quick access to font family selection directly from the TinyMCE toolbar.
- **Format Menu Entry**: Integrated option in the contextual formatting menu.
- **Customizable Fonts**: List of font families managed by the site administrator.
- **Smart Detection**: If fewer than two font families are configured, the selector is automatically hidden to avoid empty dropdowns.
